PRODCOM Classification - Interactive Jupyter Notebook

This page provides access to the interactive ClassifAI Notebook, a self-contained Jupyter notebook for classifying products according to the PRODCOM classification system using OpenAI’s language models.

📓 Interactive Notebook

The notebook is designed to be: - Self-contained: No complex dependencies (no Qdrant required) - Easy to use: Only OpenAI API Key needed - Fully documented: Step-by-step instructions included - Ready for cloud: Deployable on Onyxia/SSPCloud - Reproducible: Sample products included for immediate testing

🚀 Quick Start

Option 1: Run Locally

# Clone repository
git clone https://github.com/AIML4OS/WP10-Cluster2-ProdcomProductsClassification.git
cd WP10-Cluster2-ProdcomProductsClassification

# Install dependencies
pip install -r requirements-notebook.txt

# Open notebook
jupyter notebook notebooks/ClassifAI_notebook.ipynb

Option 2: Run on Onyxia/SSPCloud

Click the button below to launch directly on SSPCloud:

Or use this URL:

https://datalab.sspcloud.fr/launcher?service=jupyter&repo=https://github.com/AIML4OS/WP10-Cluster2-ProdcomProductsClassification&init-script=sspcloud/init-notebook-trainees.sh&cpu=4&mem=8

📚 Notebook Contents

The notebook consists of 9 major steps:

  1. Install Dependencies - Setup required Python packages
  2. Import Libraries - Load all necessary modules
  3. Setup Configuration - Configure API access and settings
  4. Load PRODCOM Data - Import classification taxonomy
  5. Define Helpers - Utility functions for data handling
  6. Define OpenAI Functions - Classification algorithms
  7. Create Sample Products - Example data for testing
  8. Classify Products - Run the classification workflow
  9. Display and Save Results - Generate output CSV

🎯 How It Works

The system classifies products by navigating through the PRODCOM hierarchy:

Product Description
    ↓
SECTION (16 options)
    ↓
DIVISION (58 options)
    ↓
GROUP (244 options)
    ↓
CLASS (615 options)
    ↓
CPA5 (2,216 options)
    ↓
CPA6 (3,500+ options)
    ↓
PRODCOM (4,000+ codes)

At each level, OpenAI selects the most appropriate code.
